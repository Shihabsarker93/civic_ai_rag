# গণপ্রজাতন্ত্রী বাংলাদেশ সরকার
**বাংলাদেশ রোড ট্রান্সপোর্ট অথরিটি**  
**পুরাতন বিমান বন্দর সড়ক**  
**এলেনবাড়ী, তেজগাঁও, ঢাকা।**  

**নং-বিআরটিএ/৫টি-১/৮৯(অংশ-৫)/২০১৪-১৮০/১(৮০)**  
**তারিখঃ ০৯-০৩-২০১৬ খ্রিঃ।**  

**অনুলিপি সদয় অবগতি ও প্রয়োজনীয় ব্যবস্থা গ্রহণের জন্য প্রেরণ করা হলোঃ**
* **১।** পরিচালক(প্রশাসন/ইঞ্জিং/এনফোর্সমেন্ট/সচিব, বিআরটিএ সদর কার্যালয়, তেজগাঁও, ঢাকা।
* **২।** পরিচালক(অপারেশন), বিআরটিএ সদর কার্যালয়, এলেনবাড়ী, তেজগাঁও, ঢাকা(তাঁকে বিধি মোতাবেক বিআরটিএ’র ব্যাংকিং সফটওয়্যারে প্রয়োজনীয় সংশোধন বা মডিফিকেশন করার অনুরোধ করা হলো)।
* **৩।** উপ-পরিচালক(ইঞ্জিং-১/২/৩), বিআরটিএ সদর কার্যালয়, এলেনবাড়ী, তেজগাঁও, ঢাকা।
* **৪।** উপ-পরিচালক(ইঞ্জিং), বিআরটিএ, ঢাকা/চট্টগ্রাম/রাজশাহী/খুলনা/বরিশাল/সিলেট বিভাগ।
* **৫।** সহকারী মেইনটেন্যান্স ইঞ্জিনিয়ার, বিআরটিএ সদর কার্যালয়, ঢাকা(বিআরটিএ’র ওয়েবসাইটে প্রকাশের অনুরোধসহ)।
* **৬।** ব্যবস্থাপক, সিএনএস লিঃ ৬/৪, ব্লক-সি, লালমাটিয়া(বর্তমানে হাউজ নং-১০৬৮, রোড নং-৬/ডি, মিরপুর ডি ও এইচ এস) ঢাকা।
* **৭।** সহকারী পরিচালক(ইঞ্জিং), বিআরটিএ, _______________ (সকল)সার্কেল।
* **৮।** চেয়ারম্যান মহোদয়ের একান্ত সচিব, বিআরটিএ সদর কার্যালয়, ঢাকা(চেয়ারম্যান মহোদয়ের সদয় অবগতির জন্য)।
* **৯।** গার্ড ফাইল।

**অনুলিপি( সদয় জ্ঞাতার্থে)ঃ**  
মাননীয় মন্ত্রীর একান্ত সচিব, সড়ক পরিবহন ও সেতু মন্ত্রণালয়, বাংলাদেশ সচিবালয়, ঢাকা।
