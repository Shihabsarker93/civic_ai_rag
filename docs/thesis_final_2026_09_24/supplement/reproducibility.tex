\section{Reproduction Procedure}
Use the checked-in plan files to recover the relevant source/configuration revisions. Verify the recorded corpus hashes and use the matching Chroma collections. Load the exact model tag and record its digest; a mutable model tag alone is not a permanent model identity. Reproducing all text exactly is not guaranteed without controlling stochastic generation and runtime versions.

For the already saved results, run the thesis audit script to regenerate inventory and result tables. It reads files and never rebuilds an index or regenerates answers. The generated manifest records hashes, code revision and the immutable Abstract hash. The original template and submitted directory are not modified.
