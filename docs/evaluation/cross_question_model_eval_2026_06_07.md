# Cross-Question CivicRAG Model Evaluation

Date: 2026-06-07
Method: CivicRAG (ours)
Models: llama3.2, llama3, qwen2.5:7b

## Evaluation Summary

These questions were intentionally harder than the earlier binary/simple questions. They combine multiple intents, typo/noisy Bangla, personal scenarios, legal exceptions, file-upload troubleshooting, and status/progress questions.

| Question | Result | Notes |
| --- | --- | --- |
| Q1: application + documents + progress | Partial | Application and document-preparation evidence is retrieved well, but progress/status tracking is not answered clearly. This needs query decomposition or a dedicated progress/status source path. |
| Q2: lost certificate | Strong | The system retrieves the correct duplicate/copy certificate rule and gives a grounded answer with timeline and fee caveat. |
| Q3: divorce / one-parent information | Medium | Retrieval finds the relevant FAQ chunks. llama3 gives the cleanest answer; llama3.2 is verbose; qwen2.5 has a Bangla corruption artifact. This should become a controlled safe-answer path instead of free LLM generation. |
| Q4: online record not found | Mixed | Retrieval finds useful verification/manual-to-online evidence, but llama3.2 hallucinates awkward UI wording. The typo/noisy phrase `অনলাইনাে` should be normalized/handled by intent detection. |
| Q5: long multi-problem query | Weak/Partial | The system answers generic online application steps but does not separately address application status, application number, upload error, or processing time. This is the strongest evidence that multi-intent query decomposition is needed. |
| Q6: outside Bangladesh | Good/Partial | The system retrieves overseas/diplomatic-mission evidence and mentions embassy/different OTP behavior. Good direction, but answer is long and should be condensed into a scenario-specific response. |
| Q7: parent-name correction | Strong/Partial | The correction safe path works and includes parent-name correction scenarios plus fee. It should still include the `প্রয়োজনীয় প্রমাণপত্র` chunk more explicitly because the user asks about uploaded documents. |

Overall verdict: the pipeline is no longer failing at basic retrieval, but complex citizen-style questions show that the next thesis improvement should be query decomposition plus more controlled safe-answer paths for high-risk service scenarios. Model comparison is still useful, but many answers are identical because CivicRAG intentionally uses deterministic grounded answer paths before falling back to the local LLM.
